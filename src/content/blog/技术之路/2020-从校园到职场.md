# 2020：从校园到职场，微服务是我的第一课

## 这一年发生了什么

2020 年 6 月，我从学校软件工程专业毕业；7 月，入职一家外企咨询公司，成为一名全栈开发工程师。疫情期间入职、远程协作，第一次体会到「文档写不清楚，队友就帮你做不对」。

参与的第一个项目是一个**百万级用户的社区类平台**。学校里写的是单体的 SSM 图书管理系统，进了公司迎接我的却是：

- **Spring Cloud 微服务架构**：注册中心、网关、服务间调用，第一次知道一个「系统」是由几十个服务拼起来的；
- **Vue.js + Element UI**：前后端分离，前端不再是我印象里的 jQuery 拼页面；
- **MyBatis-Plus / Redis / RocketMQ**：每一个都是学校没教过的名字。

## 技术上的变化

从「会写 Java」到「理解一个分布式系统的形状」：

1. **Java 基础的祛魅**：集合、多线程这些课本知识，第一次在生产代码里被真实使用（线程池参数配错导致任务堆积，排查了一整晚）；
2. **微服务入门**：理解了服务拆分的边界不是技术，而是业务——为什么用户服务和内容服务要分开，不是因为「微服务酷」；
3. **前端不再可怕**：Vue 的响应式和组件化让我意识到前后端分离真正的价值是「契约先行」。

## 个人感悟

> 在学校我以为什么都懂，工作第一年我才明白：我懂得的只是「语法」，而工程是另一门学科。

这一年最大的收获不是某个框架，而是三个习惯：

- **看官方文档而不是博客抄代码**（被老旧博客坑过 Spring Cloud 版本兼容问题）；
- **提交前自己先跑一遍**，别让测试同学当你的人肉 CI；
- **写周报**：把做过的事写清楚，本身就是一次复盘。

如果说给刚毕业的自己一句建议：**别急着学「新东西」，先把正在用的东西用到明白。**
